# 🏆 DhamaSports

O DhamaSports é um projeto acadêmico desenvolvido no curso de Análise e Desenvolvimento de Sistemas (ADS), com foco na criação de um site moderno e responsivo para uma loja de camisas de times.
Desenvolvido com HTML, CSS, JavaScript e Bootstrap, o projeto foi realizado em parceria com alunos de Administração, simulando um ambiente real de mercado — desde o levantamento de requisitos até a entrega final da aplicação.
A solução apresenta uma interface intuitiva, design responsivo e organização eficiente dos conteúdos, refletindo boas práticas de desenvolvimento front-end e experiência do usuário (UX).
O projeto foi concluído e apresentado como parte avaliativa do curso.
